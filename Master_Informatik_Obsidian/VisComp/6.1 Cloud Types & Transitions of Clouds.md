Parameters to change:
$E$ = heat emitter value
$\gamma_{heat}$ = scaling parameter
$\phi_{rel}$ = relative humidity
$\gamma_{vapour}$ = scaling parameter
$v_{perlin}$ = perlin noise frquency
$p_{perlin}$ = perin noise persistence

All other parameters: set constant at beginning of simulation

---
### What the Parameters do:
$\gamma_{heat}$, $\gamma_{vapour}$ => emission variance
$E$, $\phi_{rel}$ => altitude of upper & lower part of clouds
- $E$ bigger => higher cloud cieling
- $\phi_{rel}$ bigger => lower cloud base
$v_{perlin}$, $p_{perlin}$ = pattern of cloud structures
