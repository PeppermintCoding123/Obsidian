= <span style="color:rgb(166, 0, 255)">Crossbar Networks</span>
- every input connected to every output with crosspoint switches <span style="color:rgb(166, 0, 255)">without blocking</span>
Pro: 
	- can implement <span style="color:rgb(166, 0, 255)">all n! permutations</span> without blocking
	- <span style="color:rgb(166, 0, 255)">high Bandwidth</span>
Con: 
	- <span style="color:rgb(166, 0, 255)">1 Crosspoint switch per coloumb</span>
	- 1 crosspoint use many connection lines - <span style="color:rgb(166, 0, 255)">high cost</span>
- only $n\leq 16$ commercial
