### Type
<span style="color:rgb(166, 0, 255)">Static</span> = Connections are rigid
<span style="color:rgb(166, 0, 255)">Dynamic</span> = connections can be changed
### Topology
[[2D-Mesh Topology]], [[Hypercube Topology]], [[Star Topology]], [[Barrel shifter]], ...
### Timing control
<span style="color:rgb(166, 0, 255)">synchronus</span> = global clock
<span style="color:rgb(166, 0, 255)">asynchronous</span> = handshaking
### Switching method
<span style="color:rgb(166, 0, 255)">Circuit switching</span> = devise occupies path on network for the entire duration of data transfer
<span style="color:rgb(166, 0, 255)">packet switching</span> = information broken into small packets
### Control strategy
<span style="color:rgb(166, 0, 255)">central</span> = global controller
<span style="color:rgb(166, 0, 255)">distributed</span> = requests handled by local devices independently
