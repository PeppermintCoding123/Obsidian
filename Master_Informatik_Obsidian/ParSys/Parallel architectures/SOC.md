= System on Chip

Realization of an application mainly within the SoC, only little external wiring  
  
Components:  
• Processor  
• Memory  
• Analog and digital input and output  
• Communication interfaces (UART, SSC, I2 C, CAN, ...)  
• Programmable logic  
  
- flexible hardware for different dynamic requirements of the market  
- cost-effective and application-specific additional function blocks
