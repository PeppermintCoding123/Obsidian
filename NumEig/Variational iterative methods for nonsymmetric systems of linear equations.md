#### 2. Descent methods for nonsylnmetrie systems.
$Ax=f$ solve this

Algorithm 2.2.
Choose $x_0$    (a)
$r_0 = f-Ax_0$    (b)
$p_0 = r_0$    (c)
For $i=0$ step $1$ until Convergence Do
$a_i = (r_i,Ap_i)/(Ap_i,Ap_i)$    (d)
$x_{i+1} = x_i + a_ip_i$    (e)
$r_{i+1}=r_i-a_iAp_p$    (f)
$p_{i+1} = ...$    (g)

Choice of $a_i$ minimizes $||r_{i+1}||_2 = ||f-A(x_i+ap_i)||_2$
Algorithms differ in $p_{i+1}$

For $A$ = SPD
$p_{i+1}=r_{i+1}+b_ip_i$
$b_i = (Ar_{i+1},Ap_i)/(Ap_i,Ap_i)$

method (2.2) & (2.3) equivalent to CR - conjugate reddual method
rdirection vectors produced are $A^TA$-orthogonal: $(Ap_i,Ap_j = 0 \quad \forall i\neq j)$
$x_{i+1}$ minimize $E(w)=||f-Aw||_2$ over affine space $x_0+\langle p_0,...,p_i\rangle$

For $A$ = nonsymmetric => [[GCR - generalized conjugate residual method]]
a set of $A^TA$-orthogonal directions  generated by 
$p_{i+1}=r_{i+1} + \sum_{j=0}^ib_j^{(i)}p_j$
$b_j^{(i)}= (Ar_{i+1},Ap_j)/(Ap_j,Ap_j) \quad j\leq i$
$x_{i+1}$ minimize $E(w)$ over $x_0+\langle p_0,...,p_i\rangle$ 

(18) Vinsome [[Orthomin]]
[[Orthomin]] is modification on GCR  => **Orthomin(k)**
make $p_{i+1}$ orthogonal to last k vektors:
$p_{i+1}=r_{i+1} + \sum_{j=i-k+1}^ib_j^{(i)}p_j$

GCR & Orthomin(k) as equivalent to Conjugate residual method when $A$ = SPD

**GCR(k)**
Restart GCR periodically: every $k+1$ iterations current $x_{j(k+1)}$ is new starting guess
=> storage is same as Orthomin(k).
faster since cost per iteration is lower

**minimum residual method (MR)**
for special cases where $p_{i+1}=r_{i+1}$
if symmetric resemble method of steepest decent => super simple
